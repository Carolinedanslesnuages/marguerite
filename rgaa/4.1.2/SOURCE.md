# Source du référentiel

Fichiers officiels du **RGAA 4.1.2**, publiés par la DINUM (Direction interministérielle du
numérique) dans le dépôt [DISIC/accessibilite.numerique.gouv.fr](https://github.com/DISIC/accessibilite.numerique.gouv.fr),
dossier `RGAA/`.

- `criteres.json` : les 106 critères, leurs tests et leurs références WCAG 2.1 ;
- `glossaire.json` : les définitions du glossaire ;
- `methodologies.json` : la méthodologie de chaque test.

Récupérés le 2026-11-20, commit `ca4019f95073`. Fichiers non modifiés.
